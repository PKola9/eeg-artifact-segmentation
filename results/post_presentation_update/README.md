# Post-presentation result tables

This folder contains the main result tables generated after the thesis presentation.

## Main files

- `three_subject_holdout_metrics.csv`  
  Metrics for the three-subject held-out test sets.

- `subjectwise_fold_definitions.csv`  
  The five subject-wise cross-validation folds and their held-out test subjects.

- `subjectwise_cv_per_fold_metrics.csv`  
  Per-fold metrics for the subject-wise cross-validation baselines.

- `subjectwise_cv_mean_std_metrics.csv`  
  Mean and standard deviation summary for the subject-wise cross-validation baselines.

- `attention_flow_per_fold_metrics.csv`  
  Per-fold metrics for the attention-flow model.

- `attention_flow_mean_std_metrics.csv`  
  Mean and standard deviation summary for the attention-flow model.

- `side_by_side_dice_iou.csv`  
  Side-by-side Dice and IoU comparison across folds.

- `side_by_side_precision_recall.csv`  
  Side-by-side precision and recall comparison across folds.

- `attention_flow_dice_gains.csv`  
  Fold-wise Dice improvement of the attention-flow model compared with the previous baselines.

No smoothing/post-processing results are included in the main post-presentation comparison.
